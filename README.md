# 弹丸论破互动模拟器（AstrBot 插件）

版本：0.3.11  
适用：AstrBot 4.29.x。

本插件提供 DR1、DR2、V3 三个独立作品分区，包含游戏状态、学生互动、自由行动、礼物、羁绊、扭蛋、案件流程及群聊播报。每个群的作品进度与玩家数据按分区保存。

## 安装

1. 将解压后的 `danganronpa_simulator` 文件夹放入 AstrBot 插件目录。
2. 在 AstrBot 插件管理中加载并启用。
3. 在目标群发送 `/弹丸 帮助` 登记主动播报会话地址。
4. 群管理员可发送 `/弹丸 管理 播报测试` 验证主动消息。

运行数据保存在 AstrBot 根目录 `data/plugin_data/danganronpa_simulator/`。升级插件时只替换代码目录，不要删除该数据目录。

## 核心指令

- `/弹丸 帮助`、`/弹丸 菜单`：查看功能菜单。
- `/弹丸 世界观` 或 `/弹丸 世界观 dr1|dr2|v3`：查看或切换当前群作品。
- `/弹丸 开始`、`/弹丸 加入`、`/弹丸 状态`：开始游戏、加入游戏、查看状态。
- `/弹丸 角色列表`、`/弹丸 角色档案 角色名`、`/弹丸 聊天 角色名 [内容]`：学生资料与对话。
- `/弹丸 自由行动 角色名`、`/弹丸 赠送 角色名 礼物名`、`/弹丸 好感度 [角色名]`、`/弹丸 羁绊`：关系互动。
- `/弹丸 扭蛋`、`/弹丸 十连`、`/弹丸 背包`、`/弹丸 黑白熊币 获取途径`：礼物与货币。
- `/弹丸 签到`、`/弹丸 委托`、`/弹丸 完成委托`、`/弹丸 活动`：每日签到、角色委托与特别活动奖励。
- 私聊 `/弹丸 杀人申请` 后，按提示单独发送目标玩家 QQ 号；只允许选择已加入当前游戏世界且仍存活的其他玩家。
- `/弹丸 探索`、`/弹丸 证据`、`/弹丸 证词`、`/弹丸 学级裁判`、`/弹丸 投票 角色名`、`/弹丸 处刑`：案件流程。

## 黑白熊币奖励

黑白熊币奖励来源包括自由行动、探索地点、新证据、日常事件、章节通关、学级裁判推理与正确投票、首次解锁羁绊阶段、角色委托、每日签到和特别活动。个人奖励没有每日累计上限；同一独立奖励事件仍按事件键防止重复领取。章节通关奖励为全班共享。

## 礼物目录与喜好

- 扭蛋池按当前群选择的作品切换，只抽取该作品已列入目录的礼物。
- 礼物名称与编号依据各作品的礼物清单；资料缺失或用户清单未提供的编号不会补造。
- 角色偏好只录入有可核对资料支持的项目。未核实的偏好显示为“中等”，不增加好感度。
- “很喜欢”增加 5 点，“喜欢”增加 3 点；“中等”“不喜欢”“厌恶”均不扣分，也不增加好感度。
- 扭蛋结果只显示抽到的礼物和剩余黑白熊币，不附加角色喜好说明或原创礼物免责声明。升级时会清理旧版生成的五种原创通用礼物。

## 羁绊剧情

好感度达到 10、30、50、75 时，分别解锁新的关系阶段剧情。每个玩家与每名角色的阶段剧情独立记录，每个阶段只触发一次。剧情由当前接入模型按角色性格、当前关系阶段和互动记忆生成；不会将通用剧情冒充原作官方文本。

## 自动播报

新建群/作品分区时，自动播报与学生主动互动默认开启。每群播报仍受全局开关、群级开关、最短间隔、每日上限及静默时段控制。角色池严格受当前群作品分区限制。

## 数据与限制

- SQLite 数据库：`data/plugin_data/danganronpa_simulator/danganronpa.sqlite3`。
- 游戏进度、玩家关系、背包、记忆与羁绊阶段均持久化。
- 角色偏好尚未核实的礼物不会被模型自行猜测；未列入礼物池的原作物品不会被扭蛋抽出。
- 本插件包含原创互动流程，不是三作完整复刻；模型演绎效果取决于 AstrBot 当前配置的模型。
- 主动播报依赖当前平台适配器支持主动消息发送；需在实际部署环境验证。
